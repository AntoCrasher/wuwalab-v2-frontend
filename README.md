# wuwalab-v2-frontend

WuwaLab v2 web client. React 19, Vite, TypeScript.

```
npm install
git config core.hooksPath .githooks
npm run check
npm run dev
```

Dev server: http://localhost:8012, proxying `/api` to the backend on 8011 (the old site keeps 8001 / 8002).

Rules and folder map: `CLAUDE.md`.
